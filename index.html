// projet annuel · 2025-2026

CyberNova Solutions : concevoir, déployer, superviser

Infrastructure virtualisée d'une PME de 25 collaborateurs

Projet réalisé sous VMware Workstation, en partant d'un réseau sans gestion centralisée, sans supervision et sans sauvegarde automatisée.

Bachelor 2 · Nexa
PROJET 1

Conception

  • Analyse de l'existant et des besoins
  • Serveur Debian 12 centralisant les services
  • Comptes avec moindre privilège (sudo)
  • Sauvegarde quotidienne en Bash et cron
  • Pare-feu UFW, root SSH désactivé
PROJET 2

Déploiement

  • Windows Server 2025 : AD DS, DNS, DHCP
  • Domaine cybernova.local
  • Apache, PHP et MariaDB sur Debian
  • Application web dynamique reliée à la base
  • Tests de connectivité entre les 3 machines
PROJET 3

Supervision

  • Netdata : CPU, RAM, disque, réseau
  • Audit avec Nmap depuis Kali Linux
  • Analyse et correction d'un incident
  • Veille CVE Apache (MITRE, NVD, CERT-FR)
  • Plan de maintenance préventive

Un incident, et ce que j'en ai tiré

La page PHP affichait « Access denied for user 'root' » et ne récupérait plus les données. L'analyse a montré qu'une application web ne devrait pas utiliser le compte root de la base. J'ai créé un utilisateur dédié, limité à la seule base nécessaire, puis modifié l'application pour l'utiliser. Le service est rétabli et le risque réduit.
